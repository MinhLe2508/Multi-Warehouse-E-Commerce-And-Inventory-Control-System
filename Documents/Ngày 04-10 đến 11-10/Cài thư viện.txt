10. ENVIRONMENT (.env)
============================================================

Prisma config hiện tại dùng:
    dotenv.config({ path: '../.env' })

Vì vậy, với cấu hình hiện tại, nên đặt .env ở PROJECT ROOT:

12. POSTGRESQL EXTENSIONS
============================================================

Cần:
    pgcrypto
    vector
    pg_trgm

Migration đã tạo:

    CREATE EXTENSION IF NOT EXISTS pgcrypto;
    CREATE EXTENSION IF NOT EXISTS vector;
    CREATE EXTENSION IF NOT EXISTS pg_trgm;

Kiểm tra bằng cách:

    docker compose exec postgres psql -U warehouse -d warehouse -c "\dx"

Phải thấy pgcrypto, vector, pg_trgm và plpgsql.



============================================================
12. SETUP MÁY THÀNH VIÊN MỚI
============================================================

Bước 1 - Tạo .env ở PROJECT ROOT.

Bước 2 - Khởi động Docker:

    docker compose up -d postgres redis

Kiểm tra:
    docker compose ps

Bước 3- Backend:

    cd backend
    npm install

Bước 4 - Generate Prisma Client (Đang ở trong thư mục backend):

    npx prisma generate

Bước 5 - Apply các migration đã có:

    npx prisma migrate deploy

Bước 6 - Kiểm tra migration:

    npx prisma migrate status

Kỳ vọng:
    Database schema is up to date.

Bước 7- Seed:

    npx prisma db seed

Kỳ vọng:
    Users: 104
    Categories: 8
    Warehouses: 3
    Products: 200
    Inventory: 600
    KB Documents: 30

16. WORKFLOW HÀNG NGÀY
============================================================

Bắt đầu ngày bằng cách:
    git pull

Nếu dependency thay đổi:
    cd backend
    npm install

Nếu là P4 có migration mới hoặc sửa đổi Schema:
    cd backend
    npx prisma migrate dev --name <ten_migration>
    npx prisma generate
	
Nếu là thành viên khác sau khi git pull:
    cd backend
    npx prisma migrate deploy
    npx prisma generate

Nếu cần seed lại DEV:
    npx prisma db seed

Khởi động Docker:
    docker compose up -d postgres redis

Chạy backend:
    cd backend
    npm run start:dev
	
	
============================================================
17. KHI KHANG (P4) TẠO MIGRATION MỚI
============================================================

P4 (Migration Owner):
    cd backend
    npx prisma migrate dev --name <ten_migration>

    Kiểm tra migration SQL.
    Commit:
        backend/prisma/migrations/<migration-folder>/
        schema.prisma nếu có thay đổi
        package.json/package-lock.json nếu dependency thay đổi

    git push

Thành viên khác trong Team cần làm việc sau:
    git pull

    docker compose up -d postgres redis

    cd backend
    npx prisma migrate deploy
    npx prisma generate
